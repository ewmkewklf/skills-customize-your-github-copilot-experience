# 📘 Assignment: Embedded SW with C

## 🎯 Objective

In this assignment, students will explore embedded software development in C by writing a small program that reads sensor-like input, processes values, and controls basic system behavior using simple logic and data structures.

## 📝 Tasks

### 🛠️ Build a Simple Embedded Control Program

#### Description
Create a C program that simulates an embedded device reading a sensor value and taking action based on thresholds or conditions.

#### Requirements
Completed program should:

- Use variables and constants to represent device states or sensor values
- Read input data from the user or a predefined sample value
- Compare values using conditionals to decide what action the system should take
- Print a clear state message such as normal, warning, or emergency
- Demonstrate how embedded logic reacts to changing conditions

### 🛠️ Improve the System with Reusable Logic

#### Description
Refactor the program so the logic is easier to maintain and clearer for embedded-style software development.

#### Requirements
Completed program should:

- Use functions to organize repeated logic into reusable blocks
- Keep the code readable with clear naming for sensors, thresholds, and actions
- Include at least one simple loop or repeated check pattern
- Show how a system may monitor multiple conditions at once
- Make the output easy to understand for a beginner embedded developer

### 🛠️ Add a Practical Embedded-Style Feature

#### Description
Extend the program to include a realistic embedded behavior such as a basic alarm or status monitor.

#### Requirements
Completed program should:

- Model a device state such as idle, active, or alert
- Update the status based on measured or simulated inputs
- Provide a summary of current conditions at the end of execution
- Use clear messages that reflect an embedded system workflow
- Keep the code compact and well structured
