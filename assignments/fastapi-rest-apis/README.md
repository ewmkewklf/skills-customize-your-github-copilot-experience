# 📘 Assignment: Building REST APIs with FastAPI

## 🎯 Objective

In this assignment, students will build a small REST API using the FastAPI framework and learn how to define routes, process request data, and return JSON responses.

## 📝 Tasks

### 🛠️ Create a Basic API

#### Description
Set up a FastAPI application and create a few endpoints that return simple JSON responses for a basic resource such as books, students, or tasks.

#### Requirements
Completed program should:

- Create a FastAPI app instance
- Define at least two endpoints using different HTTP methods
- Return JSON data from each endpoint
- Use clear URL paths for the resource being managed
- Run the application locally with a development server

### 🛠️ Add Data Handling and Validation

#### Description
Extend the API so it can accept input from clients and respond to requests with meaningful data and validation.

#### Requirements
Completed program should:

- Accept request data using query parameters or request bodies
- Return specific data for a selected item by ID or another identifier
- Validate required fields before processing a request
- Handle cases where the requested item does not exist
- Display helpful error or success messages through API responses

### 🛠️ Improve the API Experience

#### Description
Polish the API with a few realistic features that make it feel complete and easy to use.

#### Requirements
Completed program should:

- Keep the API organized with clean route names and consistent response formats
- Include at least one example of creating or updating data
- Return status codes that fit the action being performed
- Write simple code comments or docstrings to explain the logic
- Make the project easy for another student to run and understand
