# 📘 Assignment: Games in Python

## 🎯 Objective

In this assignment, students will create a simple text-based game in Python while practicing loops, conditionals, user input, and string handling.

## 📝 Tasks

### 🛠️ Build the Game Structure

#### Description
Create a playable Hangman-style game in Python using a list of words and a loop that keeps asking the player for guesses until the game ends.

#### Requirements
Completed program should:

- Choose a random word from a predefined list
- Display blanks for each letter using underscores
- Accept one letter at a time from the user
- Reveal correctly guessed letters in the correct positions
- Track how many wrong guesses remain
- End the game when the word is guessed or the player runs out of attempts
- Print a clear win or lose message

### 🛠️ Improve the User Experience

#### Description
Add polish to the game so it feels complete and easy to play, including feedback after each guess and a clean game flow.

#### Requirements
Completed program should:

- Show the current guessed letters and remaining attempts after each turn
- Prevent duplicate guesses from being counted twice
- Keep the game running until the player chooses to quit or finishes a round
- Use clear, friendly messages for valid and invalid input
- Make the program easy to follow and understand for a beginner
